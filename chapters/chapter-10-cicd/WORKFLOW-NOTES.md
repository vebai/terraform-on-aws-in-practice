# GitHub Actions example

`terraform.example.yml` reproduces the full workflow listing in Chapter 10 (including the placeholders and US Region from the printed manuscript). It is **not active** because this is an educational repository.

Before enabling, review the actions versions, configure a secure AWS OIDC trust policy, replace example role ARNs, select your Region, use branch protection, choose the correct working directory and configure GitHub Environment approvals. A workflow that applies infrastructure should not be enabled by merely publishing this companion repository.
